## 3. Codebase understanding

### 3.1 Architecture notes discovered this session

- **The image rollback class never pins by tag.** `rollback-classes.ts` builds `repo@digest` from the manifest's `images[]` or `imageDigest`, and throws when a manifest has neither (`:557-570`). A doc line that offers a per-deploy tag beside "`deploy:rollback` does exactly that" is therefore wrong, however old the target.
- **The ECR policy's one rule selects `tagStatus: 'any'`.** With rule 1 gone, untagged images count toward the 50 and never expire on their own. "The newest 50 images" no longer means "the last 50 deploy tags".
- **The `cdkEnvBag` "CI enablement" comment was orphaned before this repository's history begins.** At the import commit `355c397` it already sat above `CCE_IMAGE_TAG`, with `CCE_CICD_ENABLED` two entries further down. Later, `04139c8` put the ops-alert block between them.
- **The repository has no formatter or linter.** There is no Prettier, ESLint or EditorConfig file and no lint script, and `ci.yml` runs none. Comment wrap and line length are kept by hand, to match the surrounding block.
