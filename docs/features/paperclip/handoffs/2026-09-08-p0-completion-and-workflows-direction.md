## 3. Codebase understanding

### 3.1 Architecture notes discovered this session

- **`npx` is a network dependency.** `npx <bin>` resolves a missing binary by *fetching* one from the registry. With no local compiler it installed the unrelated package `tsc@2.0.4`, whose bin prints "This is not the tsc command you are looking for" and exits 1. A build stage must never reach the network to find its compiler.
- **`--omit=dev` suppresses an explicitly named package.** npm's arborist infers a dev edge for any name already in `devDependencies`; `--no-save` only suppresses the manifest write; a node marked dev under `--omit=dev` is treated as undefined for diffing and is never reified. Naming a package on the command line does not override this. Isolation (an install directory with no manifest) does.
- **Paperclip scopes issue writes to the assignee.** `client.ts` sends every write with the acting agent's key and `config.ts` records `reconcilerKey`/`dispatchSecret` as deliberately absent, so a cross-board write by a non-assignee is refused 403 by the engine regardless of what our ACL decides.
- **`slugForUuid` throws; it does not fall back.** `mission-projection.ts` reads `createdByAgentId` and maps it, throwing `UnknownAgentError` on an unknown uuid. The literal `'paperclip'` fallback fires only when the field is *null*.
- **Paperclip ships white-labelling.** Its SPA shell carries a `PAPERCLIP_RUNTIME_BRANDING_START` injection slot, and the API exposes `/api/companies/{cid}/branding` and `/api/companies/{cid}/logo`.
